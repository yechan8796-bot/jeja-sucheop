제자수첩 개인정보처리방침

시행일: 2026년 11월 17일
제자수첩은 교사가 가르친 학생들의 기록을 교사 본인의 구글 드라이브에 저장하는 웹앱입니다. 앱 운영자는 별도의 서버를 두지 않으며, 사용자의 기록을 수집하거나 열람하거나 보관하지 않습니다.

1. 처리하는 정보

  • 사용자가 직접 입력한 학급 정보(연도, 학교, 학년, 반 이름), 학생 명부(번호, 이름, 비고), 근황, 학생 사진
  • 로그인한 구글 계정의 이메일 주소(화면 표시와 다음 로그인 편의를 위해 사용자의 브라우저에만 저장)

2. 저장 위치

  • 모든 기록은 사용자 본인의 구글 드라이브 '제자수첩' 폴더(시트, 사진, 백업)에 저장됩니다.
  • 정보는 사용자의 브라우저와 구글 서버 사이에서만 오가며, 앱 운영자의 서버를 거치지 않습니다.
  • 사용자의 브라우저에는 로그인 편의 정보(이메일), 비밀번호 오입력 횟수, 화면 설정만 저장됩니다.

3. 구글 사용자 데이터의 사용

  • 이 앱은 drive.file 권한만 요청합니다. 이 권한으로는 앱이 직접 만든 파일만 열 수 있고, 사용자 드라이브의 다른 파일은 볼 수 없습니다.
  • 구글 사용자 데이터는 기록을 저장하고 불러오는 기능에만 사용하며, 광고, 판매, 제3자 제공, 인공지능 학습에 사용하지 않습니다.
  • 이 앱의 구글 API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 보관과 삭제

  • 기록은 사용자가 지울 때까지 사용자의 구글 드라이브에 남아 있습니다.
  • 모든 기록을 지우려면 구글 드라이브에서 '제자수첩' 폴더를 삭제하세요.
  • 앱의 접근 권한은 구글 계정 > 타사 앱 및 서비스에서 언제든 해제할 수 있습니다.

5. 사용자의 책임

학생 정보는 민감한 개인정보입니다. 사용자는 구글 계정과 수첩 비밀번호를 안전하게 관리하고, 백업 파일은 암호화 상태로 보관해 주세요.
